# Space Oddity — 우주 한량

종이 인형 마법사 소녀가 되어 실제 크기의 태양계를 나는 브라우저 게임이다. 태양, 여덟 행성, 달, 목성과 토성의 큰 위성 다섯까지 모두 15개 천체가 있다. 보이저 1·2호, 허블, 제임스 웹 우주망원경도 찾아갈 수 있고, 하늘에는 은하수와 가까운 은하 넷(안드로메다, 삼각형자리, 대·소마젤란), 별자리 일곱(오리온, 북두칠성, 카시오페이아, 남십자, 전갈, 백조, 사자)이 실제 방향에 있다. 지구와 태양이 어느 쪽인지는 언제나 화살표로 보인다. 설치 없이 주소만 열면 PC와 휴대전화에서 돌아간다.

## 할 일

- **발견**: 천체 표면 50,000km 안에 처음 들어가면 수첩에 기록된다.
- **착지**: 천체 표면에 처음 닿으면 기록된다. 안으로는 들어갈 수 없다.
- **사진 임무 8개**: 사진 모드에서 "사진 저장"을 누르는 순간의 구도로 판정한다.

| 임무 | 조건 |
|---|---|
| 창백한 푸른 점 | 지구가 화면 안에 있고 겉보기 지름이 0.1도 미만 |
| 지구돋이 | 달 표면 5,000km 안에서 달과 지구를 한 화면에 |
| 개기일식 | 다른 천체가 태양을 90% 넘게 가린 순간, 태양 쪽으로 |
| 고리의 제왕 | 토성이 화면 높이의 40% 이상 |
| 대적점 | 목성이 화면 높이의 90% 이상 |
| 태양 스치기 | 태양 표면 50,000km 안에서 |
| 영웅 셀카 | 영웅을 보이게 두고 행성이나 위성이 화면 높이의 30% 이상 |
| 두 행성 한 컷 | 행성 둘이 한 화면에, 둘 다 화면 높이의 0.5% 이상 |

발견 15, 착지 15, 사진 8을 합쳐 38칸을 모두 채우면 끝이다. 기록은 브라우저에 저장되어 다시 열어도 남는다. 왼쪽의 둥근 미니맵은 태양과 행성 8개, 내 위치와 방향을 보여 주고, 행성을 누르면 그 행성을 고른다.

## 규칙

- 천체 크기는 실제 반지름을 쓴다. 지구 6,371km, 목성 69,911km, 태양 696,340km.
- 천체 사이의 빈 거리만 1/100로 줄였다. 지구와 태양 사이 빈 거리는 약 1억 4,889만km → 148만 9,000km, 해왕성까지는 약 4,500만km가 된다.
- 위성과 그 행성 사이의 빈 거리는 1/10로 줄였다. 1/100로 줄이면 달이 지구 표면 3,763km 위에 붙어 보였다. 지금은 약 37,600km 떨어져 있다.
- 모든 천체가 실제 공전 주기로 태양이나 행성 둘레를 돈다. 게임 시간은 실제의 720배라 지구 하루(자전)가 2분, 달의 공전이 약 55분, 이오의 공전이 약 3.5분이다. 천체 표면 50,000km 안에 있으면 캐릭터가 그 천체와 함께 움직인다.
- 시작 배치는 태양 둘레에 흩어 놓은 고정값이며 오늘 날짜의 실제 위치가 아니다.
- 속도 제한은 가장 가까운 천체 표면까지 거리(km)에 1/초를 곱한 값이다. 최저 0.01c(초속 약 3,000km), 최고 100c. 다가갈수록 저절로 느려지고 멀어질수록 서서히 빨라진다.

| 표면까지 거리 | 제한 속도 |
|---|---:|
| 3,000km 안 | 0.01c |
| 30,000km | 0.1c |
| 300만km | 10c |
| 3,000만km 밖 | 100c |

- 제한이 그대로라면 3초 걸려 제한 속도까지 가속하고, 손을 떼면 1초 동안 감속해 멈춘다.
- 표면 바로 앞까지 갈 수 있지만 천체 안으로는 들어갈 수 없다. 한 프레임에 천체를 통째로 지나칠 속도에서도 표면에서 멈춘다.

## 탐사선과 망원경

| 이름 | 자리 |
|---|---|
| 보이저 1호 | 태양에서 약 2억 5,400만km(실제 170AU를 1/100로 줄임), 행성들보다 북쪽 |
| 보이저 2호 | 태양에서 약 2억 1,200만km(실제 142AU), 행성들보다 남쪽 |
| 허블 우주망원경 | 지구 표면 540km 위를 돈다 |
| 제임스 웹 우주망원경 | 지구에서 태양 반대쪽으로 15만km |

실제로는 몇 m 크기라 보이지 않아서 30km 크기로 키워 그렸다. 착지하거나 수첩에 기록되지는 않는다. 화면에 들어오면 이름표가 보이고, 이름표를 누르면 고를 수 있다. 가까이 가면 저절로 느려진다.

토성 고리를 뚫고 지나가면 얼음 알갱이가 흩날린다.

## 캐릭터

얼굴 없는 종이 인형 마법사 소녀다. 은색 쌍갈래 머리, 금 테두리 흰 케이프, 줄무늬 셔츠, 발목까지 오는 흰 로브, 갈색 부츠를 하고 있다.

- 날 때: 몸을 앞으로 뉘고 두 팔을 머리 위로 뻗는다. 쌍갈래는 네 마디로 나뉘어 속도가 빠를수록 빨리 물결치고, 로브는 좁아진다. 좌우로 돌면 몸이 안쪽으로 기운다.
- 멈출 때: 1.5초 뒤 천천히 돌아서 카메라를 본다. 그 뒤 3초가 지나면 첫 동작을 하고, 이후 8 → 15초마다 동작 하나를 한다. 동작은 갸우뚱, 손 흔들기, 빙그르르, 깡충깡충, 두리번, 기지개, 끄덕끄덕, 살랑살랑, 만세, 양손 흔들기 열 가지다.
- 화면이 세로로 긴 휴대전화에서는 60% 크기로 줄어든다.

모양은 Blender로 만든 종이 공예 모델에서 가져왔다. 모델을 머리, 몸통, 로브, 팔 위아래, 다리 위아래, 쌍갈래 마디로 잘라 삼각형 667개를 `src/render/mageModel.js` 에 담았고, `src/render/hero.js` 가 이 부품을 관절에 붙여 움직인다. 모델에는 지팡이가 있지만 날 때 팔 동작과 겹쳐서 게임에는 넣지 않았다. 캐릭터 표시는 사진 모드에서 끄고 켤 수 있다.

## 조작

### PC

| 입력 | 동작 |
|---|---|
| 마우스 드래그, 방향키 | 방향 전환 |
| W / S | 전진 / 후진 가속 |
| A / D | 왼쪽 / 오른쪽 옆걸음 |
| Q / E | 좌우로 몸 돌리기 |
| Space | 즉시 정지 |
| P | 사진 모드 |
| J | 탐험 수첩 |
| M | 소리 켜기 / 끄기 |
| Esc | 일시 정지, 사진 모드 나가기 |

### 휴대전화

- 왼쪽 스틱: 방향 전환 (누르고 있으면 전진)
- 전진, 후진 버튼: 누르는 동안 가속
- 정지 버튼, 사진 모드 버튼, 수첩 버튼

화면의 천체 이름표를 누르거나 수첩에서 "목적지로"를 누르면 그 천체를 고른다. "바라보기"는 비행 방향을 그쪽으로 돌리고, "확대 관찰"은 사진 모드에서 그 천체를 화면에 맞춘다. 창을 벗어나면 비행이 일시 정지된다.

## 휴대전화에 앱으로 설치

게임 주소를 열고 홈 화면에 추가하면 주소창 없는 전체 화면 앱으로 열린다. 설치할 때 게임 파일(약 9.5MB)을 모두 받아 두므로, 그 뒤로는 인터넷 없이도 열린다. 새 판을 올리면 다음 실행 때 자동으로 바뀐다.

- 안드로이드 크롬: 메뉴 ⋮ → 앱 설치 (도움말 창의 "지금 설치" 버튼도 된다)
- 아이폰 사파리: 공유 → 홈 화면에 추가

https 주소에서만 설치할 수 있다. 깃허브 페이지 주소는 https다.

## 실행

Node.js 22 이상이 필요하다.

```bash
npm install
npm run dev
```

주소창에 `http://localhost:5173/oddity_claude/` 를 연다. Windows에서 5173번 포트가 막혀 있으면 `npm run dev -- --port 4317` 처럼 다른 포트를 쓴다.

## 시험

```bash
npm test
```

천체 배치, 제한 속도, 가속과 감속, 표면 충돌, 화면 구도 판정, 미니맵 좌표, 이름표 겹침, 사진 임무, 수첩 기록, 알림 문구를 검사한다.

## 공개

`main` 에 올리면 GitHub Actions가 빌드해서 `https://destory1984.github.io/oddity_claude/` 에 올린다. 저장소가 공개이고 Settings → Pages → Source가 "GitHub Actions"로 되어 있어야 한다.

## 구조

| 폴더 | 내용 |
|---|---|
| `src/core/` | 천체 표, 비행 규칙, 한 프레임 진행. 화면과 무관한 계산이라 전부 시험한다. |
| `src/render/` | Babylon.js로 천체, 태양, 별, 캐릭터를 그린다. 캐릭터 모양 데이터는 `mageModel.js` 다. |
| `src/ui/` | 입력, 화면 표시, 미니맵, 사진 모드, 알림. |

## 출처

지구, 금성, 이오, 유로파, 가니메데, 칼리스토, 타이탄은 NASA 탐사 지도를 썼다. 화성, 목성, 토성, 해왕성은 Solar System Scope의 2048×1024 지도(CC BY 4.0)를 썼다. 수성, 천왕성, 달은 셰이더로 그렸다. 캐릭터(얼굴 없는 종이 인형 마법사)는 Blender로 종이 공예 모델을 만들어 삼각형 667개로 뽑았고, 권리를 보유한다(아래 라이선스 참고). 자세한 출처는 [THIRD-PARTY.md](THIRD-PARTY.md) 에 있다.
