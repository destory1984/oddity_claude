이웃집 할머니가 적다 만 탐험 수첩 210칸을 소라가 대신 채우는 이야기다. 할머니는 손글씨 쪽지와 엽서 답장으로만 나온다.

자세한 규칙과 숫자는 모두 [상세기획서](docs/Space-Oddity-상세기획서.md)에 있다. 이 문서는 무엇이 있는지만 짧게 적는다. 날짜별로 무엇이 바뀌었는지는 [바뀐 것들](바뀐-것들.md)에 한 줄씩 있다.

## 규칙

- 천체 크기는 실제 반지름을 쓴다. 지구 6,371km, 목성 69,911km, 태양 696,340km.
- 천체 사이의 빈 거리만 1/100로 줄였다. 지구와 태양 사이 빈 거리는 약 1억 4,889만km → 148만 9,000km, 해왕성까지는 약 4,500만km가 된다.
  - 이유: 이동이 지루하지 않게 하려는 것이다. 실제 거리 그대로면 가장 빠른 100c(초속 약 3,000만km)로 쉬지 않고 날아도 지구에서 해왕성까지 2분 30초, 보이저 1호까지 14분 동안 빈 우주만 본다. 1/100이면 각각 1.5초와 8.5초 거리다.
- 위성과 그 행성 사이의 빈 거리는 1/10로 줄였다. 달은 지구 표면에서 약 37,600km 떨어져 있다.
  - 이유: 처음에는 위성도 1/100로 줄였는데, 달이 지구 표면 3,763km 위에 붙어 보였고 타이탄이 토성 고리 안에 들어갔다.
- 모든 천체가 실제 주기로 공전하고 자전한다. 게임 시간은 실제의 50배라 지구 하루가 29분, 달의 공전이 약 13시간 7분이다.
  - 이유: 실제 시간 그대로면 한 번 노는 동안 낮과 밤도, 위성도 움직이지 않는다. 처음에는 720배였는데 지구의 땅이 적도에서 1초에 333km씩 움직여 내려서기가 어려웠다. 180배와 100배를 거쳐 50배(1초에 23km)로 낮췄다.
- 속도 제한은 가장 가까운 천체 표면까지 거리(km)에 0.5/초를 곱한 값이다. 최저 0.01c, 최고 100c. 다가갈수록 저절로 느려진다.
- 천체 안으로는 들어갈 수 없고, 부딪혀도 잃는 것이 없다.
- 한 번 가 본 곳은 이름표나 수첩, 큰 지도에서 순간 이동한다(6초). 탐사선이면 바로 도킹하고, 이야기 장소면 바로 그 곁에 내려선다.
- 기록은 브라우저에만 저장된다.
- 게임을 열면 방문 한 번이 GoatCounter에 세어진다. 쿠키는 쓰지 않고, 쪽 경로·제목·유입 주소·화면 크기만 보낸다.

### 휴대전화

- 화면 드래그: 방향 전환
- 오른쪽 아래의 단추 아홉(세 줄): 가운데가 정지, 그 위·아래·왼쪽·오른쪽이 이동 단추로 누르는 동안 그쪽으로 미끄러진다. 맨 위 줄 왼쪽이 후진, 오른쪽이 전진, 맨 아래 줄 왼쪽이 뒤 보기, 오른쪽이 우주멍(글자와 단추를 모두 숨긴다)이다
- 이름표를 누르면 그것을 고른다. 이름 칸에 명당, 오로라, 집 단추가 붙는 천체가 있다. 도킹했거나 장소에 내려섰을 때는 이름 칸에 "도킹 풀기"와 "그날로" 단추가 붙는다. 오른쪽 위 둘째 줄의 그림 단추 셋: 눈(바라보기)은 그쪽으로 돌고, 자물쇠(목표 고정)는 화면에 붙잡아 두고, 돋보기(확대 관찰)는 가까이에서 돌려 보며 읽을거리를 띄운다
- 미니맵을 누르면 큰 지도가 열려 갈 곳을 고르고 순간 이동한다
- 위쪽 단추: 첫 줄에 수첩, 효과음, 배경 음악, 설정(도움말은 설정의 둘째 쪽), 둘째 줄 맨 왼쪽에 사진. 수첩이나 설정을 열거나 다른 앱으로 가면 게임이 저절로 멈춘다

## 휴대전화에 앱으로 설치

안드로이드는 정식 출시 뒤에 구글 플레이에서 받으면 된다. 브라우저로도 된다: 게임 주소를 열고 홈 화면에 추가하면 주소창 없는 전체 화면 앱으로 열린다. 설치할 때 게임 파일(약 40MB)을 모두 받아 두므로 그 뒤로는 인터넷 없이도 열린다.

- 안드로이드 크롬: 메뉴 ⋮ → 앱 설치
- 아이폰 사파리: 공유 → 홈 화면에 추가

브라우저는 Chrome 111, Safari 16.4(둘 다 2023년 3월) 이상에 맞춰 만든다. 2022년 초보다 오래된 브라우저에서는 게임이 열리지 않고, 브라우저를 업데이트하라는 안내가 뜬다.

## 의견을 주는 법

[이슈](https://github.com/destory1984/oddity_claude/issues)에 적어 주면 된다. 이 세 가지가 가장 궁금하다.

1. 달까지 가 보았는가. 그만두었다면 어디서 그만두었는가.
2. 비행 연습에서 어려웠던 과정이 있었는가. 있었다면 몇 번째인가.
3. 어디서 무엇을 눌러야 할지 몰랐던 적이 있는가.

쓴 기기(휴대폰 이름, 브라우저)도 함께 적어 주면 좋다. 이런 것도 반갑다.

- 휴대폰이 뜨거워지거나 화면이 끊겼다면 그때 어디에 있었는지(천체 이름이나 장면 이름)
- 가장 마음에 든 볼거리나 "그날로" 장면
- 게임에 넣고 싶은 것(가 보고 싶은 곳, 보고 싶은 장면, 있으면 좋을 기능)
- 틀린 사실이나 어색한 번역(영어, 일본어, 중국어). 화면을 찍어 붙이면 찾기 쉽다

## 실행과 시험

Node.js 22 이상이 필요하다.

```bash
npm install
npm run dev
```

주소창에 `http://localhost:5173/oddity_claude/` 를 연다. Windows에서 5173번 포트가 막혀 있으면 `npm run dev -- --port 4417` 처럼 다른 포트를 쓴다.

```bash
npm test
```

시험은 635개다. 화면과 무관한 계산(`src/core/`)을 모두 검사한다.

`main` 에 올리면 GitHub Actions가 빌드해서 위 주소에 올린다. 버전은 `package.json` 의 것이고 커밋할 때마다 하나씩 올린다. 설정 창의 제목 옆에 버전과 고친 날짜가 뜬다.

## 구조

| 폴더 | 내용 |
|---|---|
| `src/core/` | 천체 표, 비행 규칙, 한 프레임 진행. 화면과 무관한 계산이라 전부 시험한다 |
| `src/render/` | Babylon.js로 천체, 태양, 별, 탐사선, 캐릭터를 그린다 |
| `src/ui/` | 입력, 화면 표시, 미니맵, 사진 모드, 알림 |
| `public/assets/` | 천체 지도, 캐릭터 도트 그림 333장, 이야기 장소의 실제 사진 111장과 그림 8장, 별자리와 은하 그림 35장, 이야기 그림 46장 |
| `build/` | 번역 도구, 그림 발주, 버전 표시, 홍보 동영상을 만드는 스크립트([build/promo](build/promo/README.md)) |
| `docs/` | 상세기획서, 이야기, 그림 발주서 |
