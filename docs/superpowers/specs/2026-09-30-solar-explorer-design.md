# Oddity B 단계: 태양계 탐험 게임 설계서

- 날짜: 2026-09-30
- 앞 단계: `2026-09-30-foundation-design.md` (A 단계)
- 결정 방식: 사용자가 4시간 자리를 비우며 "혼자 생각해서 재미있는 게임으로 만들어 놔"라고 맡겼다. 아래 결정은 그 위임에 따라 구현자가 정했고, 사용자가 돌아오면 검토받는다.

## 1. 무엇이 부족했나

A 단계까지의 Oddity는 경치를 보며 나는 장난감이다. 할 일이 없고, 지구·달·태양 세 곳뿐이라 몇 분이면 다 본다. 게임이 되려면 세 가지가 필요하다.

1. 갈 곳: 행성이 더 있어야 한다.
2. 할 일: 가서 무엇을 해야 하는지 목표가 있어야 한다.
3. 남는 것: 한 일이 기록되어 다음에 또 열 이유가 있어야 한다.

## 2. 핵심 반복

> 목적지를 고른다 → 날아간다 → 새 천체를 발견하고 표면에 내려앉는다 → 멋진 구도를 찾아 사진 임무를 달성한다 → 탐험 수첩이 채워진다 → 다음 목적지를 고른다

## 3. 갈 곳: 수성 → 해왕성

원 기획서 18장 7단계 그대로다. 실제 반지름과 태양 기준 평균 거리(긴반지름)를 쓰고 표면 사이 빈 거리만 1/100로 줄인다.

| 천체 | 반지름(km) | 태양까지 평균 거리(km) |
|---|---:|---:|
| 수성 | 2,439.7 | 57,909,050 |
| 금성 | 6,051.8 | 108,208,000 |
| 지구 | 6,371 | 149,597,870.7 |
| 화성 | 3,389.5 | 227,939,200 |
| 목성 | 69,911 | 778,570,000 |
| 토성 | 58,232 | 1,433,530,000 |
| 천왕성 | 25,362 | 2,872,460,000 |
| 해왕성 | 24,622 | 4,495,060,000 |

- 행성은 태양 둘레 여러 방향에 흩어 둔다. 한 줄로 늘어서면 한 방향으로만 날게 되어 재미가 없다. 방향은 고정값이며 실제 날짜의 위치가 아니다.
- 지구 방향과 시작 장면(지구 반쪽 낮, 태양 90도)은 A 단계 그대로다.
- 외부 텍스처를 내려받으려면 사용자 허락이 필요하므로, 새 행성은 셰이더로 그린다: 목성·토성·천왕성·해왕성은 띠 무늬, 목성은 대적점, 수성·화성은 얼룩과 극관, 금성은 두꺼운 구름. 토성에는 고리를 단다. 고리는 통과할 수 있다.
- 광속의 1,000배면 해왕성(압축 거리 약 4,500만km)까지 1초 남짓이다. 이동 시간이 아니라 도착한 뒤의 경치와 임무가 게임의 중심이다.

## 4. 할 일: 발견, 착지, 사진 임무

### 4.1 발견과 착지

- **발견**: 어떤 천체의 표면에서 50,000km 안(별 근처 구역)에 처음 들어가면 "새 천체 발견: 화성" 알림과 함께 수첩에 기록한다. 지구는 시작할 때 이미 발견한 것으로 친다.
- **착지**: 표면에 처음 닿으면 "착지 기록: 화성" 알림과 함께 기록한다. 태양도 착지 대상이다(표면에 닿는 것이 게임상 가능하다).

### 4.2 사진 임무

사진 모드에서 "사진 저장"을 누르는 순간의 구도로 판정한다. 판정은 순수 계산이라 시험할 수 있다.

| 임무 | 조건 |
|---|---|
| 창백한 푸른 점 | 지구가 화면 안에 있고, 겉보기 지름이 0.1도보다 작다 |
| 지구돋이 | 달 표면에서 5,000km 안에서, 지구와 달이 함께 화면 안에 있다 |
| 개기일식 | 태양 방향이 화면 안에 있고, 다른 천체가 태양을 90% 넘게 가린다 |
| 고리의 제왕 | 토성이 화면 안에 있고, 겉보기 지름이 화면 높이의 40% 이상이다 |
| 대적점 | 목성이 화면 높이의 90% 이상을 채운다 |
| 태양 스치기 | 태양 표면에서 50,000km 안에서 찍는다 |
| 영웅 셀카 | 캐릭터를 보이게 두고, 행성이나 달이 화면 높이의 30% 이상을 채운다 |
| 두 행성 한 컷 | 행성 둘 이상이 함께 화면 안에 있고, 둘 다 화면 높이의 0.5% 이상이다 (위성, 태양 제외) |

- "화면 안"은 천체 중심 방향이 카메라 시야 사각형 안에 있다는 뜻이다. 화면 비율을 반영한다.
- 한 장으로 여러 임무를 달성할 수 있다. 달성하면 "사진 임무 달성: 지구돋이" 알림을 띄운다.

## 5. 남는 것: 탐험 수첩

- 머리글의 "수첩" 버튼(PC는 J 키)으로 연다. 여는 동안 비행은 일시 정지된다.
- 천체마다 한 줄: 이름, 발견 여부, 착지 여부, 지금 거리, "목적지로" 버튼. 누르면 그 천체를 선택하고 바라본다.
- 아래에 사진 임무 8개와 달성 여부. 조건 문장을 힌트로 보여 준다.
- 맨 위에 진행률: "발견 3/9 · 착지 1/9 · 사진 2/8".
- 기록은 브라우저 `localStorage` 에 저장한다. 읽기·쓰기는 try/catch로 감싸고, 저장이 안 되는 환경에서는 그 창 안에서만 기록된다.
- "기록 지우기" 버튼은 확인 창을 거친다.

## 6. 화면 정리

- 천체가 10개가 되면 화면 밖 화살표 표지가 가장자리에 몰려 겹친다. 화면 밖 화살표는 **선택한 천체와 가장 가까운 천체**만 보인다. 화면 안에 보이는 천체의 이름표는 모두 보인다.
- 오른쪽 패널에 "지금 출발하면 약 N초"를 보인다. 실제 비행 규칙(`step`)을 목표를 향해 빠르게 돌려 계산한다(원 기획서 20장 "목적지 선택 및 예상 도착 시간").

## 8. 검사

- 모든 천체 쌍: 압축 중심 거리 > 반지름 합, 빈 거리 = 원래의 1/100, 천체끼리 겹치지 않음.
- 시작 장면 90도, 시작 위치 지구 상공 9,129km 유지.
- 임무마다 달성하는 구도와 달성하지 못하는 구도를 하나씩 시험.
- 발견은 한 번만, 착지는 한 번만 사건을 낸다. 기록은 되돌아가지 않는다.
- 예상 도착 시간: 지구로 곧장 가는 값이 실제 `step` 반복과 같다. 도달할 수 없으면 null.
- 브라우저: 행성 8개가 보이고, 화면 밖 화살표가 겹치지 않고, 수첩이 열리고 닫히며, 새로 고침 뒤에도 기록이 남는다. 콘솔 오류 0개.
