# 무전 친구: 단서 그물 이야기 설계 (2026-10-22)

## 1. 왜 만드는가

사용자가 "우주정거장에 가면 누굴 만나서 어떤 이야기를 하고.. 이런 식의 게임 진행은 어때?"라고 물었다. 세 가지 방식 가운데 아우터 와일즈처럼 들은 말이 다음 갈 곳의 단서가 되는 방식(C)을 골랐다.

지금 게임에서 사람의 기척은 할머니의 쪽지와 엽서 답장뿐이다. 이 갈래는 우주에서 사람(과 탐사선의 기록)을 만나 이야기를 듣고, 그 말을 따라 숨은 장소를 찾아가게 한다.

사용자가 정한 것:

| 질문 | 답 |
|---|---|
| 261칸 전부를 단서로 잠그는가 | 아니다("무리수겠지?"). 칸은 지금처럼 열어 두고, 단서는 길잡이, 잠금은 끝의 숨은 장소 다섯에만 건다 |
| 그물 끝에 무엇이 있는가 | 할머니의 무전 친구 이야기 |
| 친구는 누구인가 | 무전 소년이 탐사선 기술자가 되고, 늘그막에 우주정거장에 올라 할머니를 부른 사람(1, 2번을 섞음) |
| 친구는 지금 | 살아 있고, 끝에 할머니와 다시 이어진다 |
| 다시 이어지는 장면 | 보여 주지 않는다. 이튿날 할머니의 쪽지로 듣는다 |
| 누구를 만나는가 | 정거장 둘, 땅 위 시설 셋의 사람, 그리고 탐사선의 기록 |
| 뼈대 | 규칙을 한 파일에 모은다(A). 수첩의 그물 그림도 넣는다(C, "C도 넣어") |

지키는 규칙(`docs/스토리-할머니의-수첩.md`):

- 할머니의 얼굴과 목소리는 나오지 않는다. 손글씨로만 나온다.
- 할머니는 지어낸 인물이지만 사건은 실제로 있었던 것이다. 이 갈래의 인물도 모두 지어내고, 그들이 걸친 사건(탐사선, 날짜, 장소)은 실제 것을 쓴다. 실제 우주비행사나 기술자를 인물로 쓰지 않는다.
- 구경과 읽기는 모두의 것이다. 이 갈래는 하고 싶은 사람만 하고, 하지 않아도 막히는 것이 없다.

## 2. 이야기

### 하야시 쇼타 (지어낸 인물)

- 1955년 일본 규슈의 바닷가 마을에서 태어났다.
- 1973년, 열여덟 살에 아마추어 무전으로 바다 건너 한국의 열아홉 살 할머니와 처음 닿았다. 둘은 서로 본 하늘을 적어 보냈다.
- 자라서 일본의 탐사선 기술자가 되었다. 아카쓰키(2010년 발사)와 하야부사2(2014년 발사)는 사람들의 이름과 글을 싣고 갔고, 그는 그 사이에 할머니만 알아볼 표시를 몰래 넣었다.
- 늘그막에 기술자 자격으로 국제우주정거장의 일본 실험실 "기보"에 올라가 무전으로 할머니를 불렀다. 할머니는 그 무렵 무전기를 접은 뒤라 그 부름을 듣지 못했다.
- 지금도 살아 있다.

실제 사실로 쓰기 전에 출처로 다시 확인할 것: 하야부사2와 아카쓰키가 실은 이름과 글의 방식과 수, 하야부사2 표적 표지를 류구에 떨어뜨린 날, 귀환 캡슐이 오스트레일리아 우메라에 내린 날(2020년 12월 6일), 아카쓰키가 금성 궤도에 다시 든 날(2015년 12월 7일).

### 만나는 이

모두 지어낸 인물이다. 얼굴 그림이 있다.

| id | 어디 (게임 안의 id) | 누구 | 아는 것 |
|---|---|---|---|
| `issCrew` | 국제우주정거장 (`iss`, 도킹) | 지금의 당번 우주비행사 | 기보 실험실에 남은 그의 무전 일지 |
| `tiangongCrew` | 톈궁 (`tiangong`, 도킹) | 승무원 | 그의 부름을 우연히 엿들은 날 |
| `tanegashimaCrew` | 다네가시마 우주센터 (`tanegashima`, 이야기 장소) | 은퇴한 발사 요원 | 젊은 날의 그와 이름 칩 이야기 |
| `vlaCrew` | VLA 전파망원경 (`vla`, 이야기 장소) | 연구원 | 무전 소년이 전파천문학에 빠진 까닭 |
| `naroCrew` | 나로우주센터 (`naro`, 이야기 장소) | 발사 요원 | 할머니 쪽 이야기, 한국의 옛 무전가들 |

### 탐사선의 기록

얼굴 대신 탐사선 모형이 나온다. 사람처럼 말하지 않고 기록장의 짧은 줄로 쓴다. (예: "2014.12.03 발사. 이름 판 둘째 줄 끝, 호출 부호 하나 더 실림." 날짜는 쓸 때 실제 것으로 맞춘다.)

| id | 탐사선 (도킹) |
|---|---|
| `hayabusa2Log` | 하야부사2 (`hayabusa2`) |
| `akatsukiLog` | 아카쓰키 (`akatsuki`) |
| `bepiLog` | 베피콜롬보 (`bepiColombo`) |

### 숨은 장소 다섯

단서가 모여야 열린다. 열리기 전에는 이름표도 지도 점도 없다.

| id | 자리 | 열리는 조건(예) |
|---|---|---|
| `ryuguMarker` | 소행성 류구, 하야부사2가 표적 표지를 떨어뜨린 자리 | 하야부사2 기록 + 다네가시마의 말 |
| `woomera` | 하야부사2 귀환 캡슐이 내린 오스트레일리아 사막 | 하야부사2 기록 + 베피콜롬보 기록 |
| `akatsukiOrbit` | 아카쓰키가 5년 만에 금성 궤도에 다시 든 자리 | 아카쓰키 기록 + VLA의 말 |
| `shotaShore` | 그가 처음 무전을 쏜 규슈의 바닷가 마을 | 나로의 말 + 톈궁의 말 |
| `kiboWindow` | 국제우주정거장 기보의 창 | 위의 넷을 모두 찾음 |

조건의 짝은 글을 쓰며 다듬는다. 다만 어느 단서를 먼저 얻든 결국 다섯이 모두 열려야 한다(검사로 지킨다).

### 끝

기보의 창에서 그의 호출 부호를 얻는다. 호출 부호는 실제로 누군가에게 주어졌을 수 있는 꼴을 피한다. 그다음 게임을 다시 열거나 실제 시간으로 10분이 지나면 할머니의 쪽지가 온다.

> 어젯밤, 오십 년 만에 무전기를 켰단다. (전문은 글을 쓸 때 정한다)

이 쪽지로 이 갈래가 끝난다. 큰 줄기의 끝(창백한 푸른 점, 대문 앞)은 그대로다.

## 3. 어떻게 돌아가는가

### 규칙 파일: `src/core/radioFriend.js`

판단은 모두 이 파일의 순수 함수가 하고, `main.js` 는 묻기만 한다(맴돌기를 `core/orbitLock.js` 로 모은 것과 같은 까닭).

- `SPEAKERS`: 만나는 이 8곳. `{ id, kind: 'person' | 'log', at: { craft } | { site }, portrait, visits: [{ needs: [단서 id], lines: [대사], gives: [단서 id] }] }`
- `CLUES`: 단서 20개 안팎. `{ id, text, from: speakerId, points: 숨은 장소 id 또는 만나는 이 id, at: [x, y] }` (`at` 은 그물 그림의 자리, 0 → 1)
- `HIDDEN`: 숨은 장소 다섯. 이야기 장소와 같은 꼴(`type: 'surface' | 'near'`, `body` 또는 `target`, `latDeg`, `lonDeg`, `withinKm`)에 `needs: [단서 id]` 를 더한다.
- 함수:
  - `nextVisit(radio, speakerId)`: 지금 들을 만남, 없으면 null. "무전" 단추를 띄울지 이것으로 정한다.
  - `hear(radio, speakerId)`: 그 만남을 들은 뒤의 새 기록.
  - `openHidden(radio)`: 열린 숨은 장소 id 목록.
  - `foundHidden(radio, state, bodies, craft)`: 지금 다다른 숨은 장소.
  - `sanitizeRadio(raw)`: 저장소에서 읽은 것을 거른다.

### 기록

`progress.radio = { visits: { [speakerId]: 들은 만남 수 }, clues: [id], found: [id], callSign: bool, noteAt: 시각 | null, noteRead: bool }`. 수첩 기록과 함께 저장하고 "기록 지우기" 때 함께 지운다. 261칸 셈에는 들지 않는다.

### 만나는 법

- 정거장이나 탐사선에 도킹했을 때, 또는 땅 위 시설에 내려갔을 때(이야기 장소에 머묾), `nextVisit` 이 있으면 이름판에 금빛 "무전" 단추가 뜬다. 저절로 튀어나오지 않는다.
- 누르면 할머니 쪽지의 카드 화면(`ui/noteCard.js`)을 다시 써서 얼굴 그림과 두세 마디를 보인다. 단서를 얻으면 알림으로 "수첩에 적었습니다"라고 알린다.
- 숨은 장소가 열리면 이름표가 생기고, 다다르면 카드(사진 또는 그림, 짧은 글)가 뜬다.

### 수첩의 "무전" 탭

- 수첩에 여덟째 탭 "무전"을 둔다. 402px 화면에 여덟 탭이 들어가는지 재고, 넘치면 탭의 글자를 빼고 그림만 남긴다.
- 탭은 별자리처럼 점과 선으로 그린 그물 그림이다. 점은 만난 이, 단서, 숨은 장소이고 선은 이어짐이다. 가운데에는 젊은 쇼타의 무전기 그림이 있다.
- 아직 모르는 점은 희미한 자리만 보인다. 점을 누르면 그림 아래 칸에 그 말이 펼쳐진다. 열린 숨은 장소의 점에는 "순간 이동" 단추가 붙는다.
- 글자는 점 옆에 쓰지 않고 아래 칸에만 쓴다(좁은 화면 때문).

## 4. 그림, 글, 번역

- 그림: 인물 얼굴 다섯, 젊은 쇼타의 무전기 앞 모습 하나, 숨은 장소 카드에 쓸 그림이나 사진. 소라와 같은 도트 결로 Codex에 주문하고(`build/art-order.sh`), 시안을 한 장에 늘어놓아 사용자가 고른 것만 넣는다.
- 글: 대사 100줄 안팎, 단서 20줄 안팎, 숨은 장소 카드 다섯, 할머니의 마지막 쪽지 하나.
- 번역: 영어, 일본어, 중국어를 같은 커밋에 넣는다. 일본 쪽 인물의 일본어는 특히 결을 살핀다.
- 사진을 받을 때마다 파일 이름과 크기를 말하고 사용자의 허락을 받는다. 오늘 정한 대로 사진은 작게 줄인다.

## 5. 검사

- 그물: 모든 숨은 장소가 단서만으로 열린다. 막다른 단서가 없다. 모든 단서에 들려준 이가 있고, 모든 만남의 `needs` 는 다른 곳에서 얻을 수 있다. 어떤 차례로 만나도 결국 다섯이 모두 열린다(모든 차례를 따라가 보는 검사).
- 기록: 저장과 불러오기, 망가진 저장값 거르기, "기록 지우기".
- `main.js`: 숨은 장소와 만나는 이의 id가 천체, 탐사선, 이야기 장소, 볼거리의 id와 겹치지 않는다(볼거리 "tycho"가 티코를 망가뜨린 일이 있다).
- 화면: 402 × 657에서 네 언어로 카드와 탭을 직접 본다.

## 6. 만드는 순서

한 번에 다 하지 않고 넷으로 나눈다. 단계마다 커밋하고, 2단계 뒤에 사용자에게 보인다.

1. 규칙 파일, 검사, 기록 저장(화면 없음)
2. "무전" 단추와 대화 카드. 국제우주정거장 한 사람만 넣어 사용자에게 보인다
3. 나머지 만나는 이 일곱, 숨은 장소 다섯, 그림
4. 수첩의 그물 그림과 할머니의 마지막 쪽지

## 7. 하지 않는 것

- 261칸을 단서로 잠그지 않는다.
- 할머니의 목소리나 얼굴을 보이지 않는다.
- 대화에 고르는 선택지를 두지 않는다. 읽고 넘긴다.
- 아우터 와일즈의 고유한 것(시간 되풀이, 옛 종족, 그 게임의 화면 생김새)은 가져오지 않는다. "아는 것이 열쇠"라는 갈래의 틀만 빌린다.
